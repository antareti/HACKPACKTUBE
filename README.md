**HACKPACKTUBE** — это персональный медиа-центр с глубокой кастомизацией в стиле "Cyberpunk/Matrix". Система спроектирована для обхода стандартных ограничений и обеспечения прямого доступа к зашифрованным видео-архивам и приватному контенту.

---

## 🛠 ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

* **UI/UX:** Адаптивный неоновый интерфейс с цветовой схемой `Neon Blue` и `Dark Surface`.
* **CORE:** Чистый HTML5/CSS3 и ванильный JavaScript. Никакого лишнего мусора, только скорость.
* **PRIVATE ZONE:** Отдельный сегмент **+18** с интригующими тематическими превью и прямой трансляцией.
* **RESTRICTED MODE:** Полная симуляция админ-панели с правами доступа уровня "My Lord".

---

## ⚡ КЛЮЧЕВЫЕ ОСОБЕННОСТИ

1.  **BitSniffer Integration:** Полная интеграция с экосистемой `bitsniffer`.
2.  **Unrestricted Player:** Обход стандартных интерфейсов для максимального погружения.
3.  **Adaptive Grid:** Динамическое разделение между "Главной" и "Личным каналом".
4.  **No-Censorship:** Раздел ограниченного доступа с визуальной имитацией закрытых сессий.
